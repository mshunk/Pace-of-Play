To install as a true Home Screen web app:
1. Upload all files in this folder to an HTTPS web host.
2. Open the hosted page in Safari on iPhone.
3. Tap Share > Add to Home Screen.
4. Enable Open as Web App if offered, then tap Add.

The service worker is included so the app can work offline after its first successful hosted load.
Opening index.html directly from Files is useful for testing but does not provide the full installed/offline web-app behavior.
